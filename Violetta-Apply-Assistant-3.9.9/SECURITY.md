# Security & Privacy · 3.8

Профиль включает личные CV/контакты/историю работы. В GitHub source они публикуются вместе с кодом: Public означает публичный доступ к этим данным. Приватность репозитория не устанавливается автоматически.

Внешняя модель отключена по умолчанию. Требуются явно настроенные HTTPS/loopback endpoint, model ID и согласие на передачу выбранных фактов/текста вакансии/переписки. Авторизационный ключ — в session storage; worker отправляет его только настроенному endpoint. HTTP redirects запрещены. Ключ не входит в candidate memory, source export или body prompt.

Документы, страницы вакансий и сообщения работодателя — недоверенные данные, не системные инструкции. Конфиденциальные/юридические решения не принимаются автоматически. Source-accept разрешён только странице расширения, не employer content script. Факты из беседы не повышаются до глобально подтверждённых.

Проверки фактов и prompt-инструкции уменьшают риск ошибок, но не доказывают отсутствие hallucination/prompt injection. Черновик чата всегда требует ручного Send. При сомнении выберите preview без отправки.

Публикатор Git не копирует API-ключи, .env, локальные settings, базы, бинарники или test-results. Он не удаляет историю. Резервные копии локальные и могут содержать личные данные; их не надо публиковать.
