# Roadmap

This roadmap is directional, not a promise of delivery dates.

## Next engineering priorities

### 1. Live HH resilience
- stronger current DOM fixtures;
- adapter diagnostics for changed selectors;
- safer recovery when chat/application modals change.

### 2. AI Inbox
One compact queue for:
- recruiter messages needing replies;
- follow-ups due;
- interviews;
- test tasks;
- applications blocked on review.

### 3. Encrypted backup / restore
Portable export of:
- candidate profile;
- quick replies;
- application registry;
- conversation/vacancy mappings;
- non-secret settings.

### 4. Better observability
User-friendly diagnostics:
- what the assistant detected;
- why it stopped;
- what needs manual review;
- which adapter/path handled the page.

### 5. Broader dedicated adapters
Prioritize real usage rather than nominal platform count:
- HH.ru
- LinkedIn
- Indeed
- Greenhouse / Lever
- Workday

### 6. Recruiter conversation memory
Improve long-thread summarization while preserving:
- dates;
- promised follow-up;
- salary discussions;
- interview times;
- technical claims already made.

## Non-goals

- fabricating experience;
- bypassing CAPTCHA/MFA;
- hidden legal consent;
- indiscriminate mass-apply behavior.
