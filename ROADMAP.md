# Roadmap after 6.0 RC1

Freeze additional feature scope until the RC is tested by the user. This is not a 100% completion claim.

Acceptance: upgrade without losing existing history; verify HH Analysis/Apply/questionnaire/Back; export and restore an encrypted backup; verify the native IndexedDB vault; verify Shadow never affects Fit; check GitHub source-only publication on Windows.

Deferred engineering: migrate all operational stores to an indexed data layer only with measured scale pressure; implement a genuinely private external working vault with tested migration; add a second provider only after live validation; improve model quality using real held-out data.

No new feature should bypass confirmed candidate facts, consent or exact vacancy identity. Never treat repeated clicks or missing recruiter responses as stronger training evidence than they are.
