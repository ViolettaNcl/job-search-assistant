VIOLETTA APPLY ASSISTANT 5.0.0 FOUNDATION — START HERE
============================================

NORMAL USE
----------
1. Extract the ZIP.
2. Open Chrome -> chrome://extensions
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the extension folder from this FULL bundle.
6. Grant HH.ru / HeadHunter access if Chrome asks.
7. Reload already-open HH tabs once.

HH SEARCH PAGE — NEW IN 4.0
---------------------------
⚡ Analyze page        -> analyzes unique rendered vacancies with bounded concurrency.
Fit badge              -> explainable rules-v1 score with reasons/risks.
Filters                -> All / No calls / Fit / Ready / Saved.
Очередь                -> user-controlled Apply / Show / Save / Skip actions.
⚙                     -> Job Preference Profile and Fit threshold.

EXISTING CARD ACTIONS
---------------------
Analysis               -> exact full vacancy + call-duty check.
✦ Отклик + письмо      -> vacancy-specific application and cover letter.

QUESTIONNAIRE
-------------
Confirmed answers are auto-filled when safe.
Reviewable human drafts are marked for checking.
Unknown factual/legal values are not fabricated.

MEMORY
------
Analysis, Fit Score/features, queue decisions, application and questionnaire state are stored by vacancyId and restored after Back/reload/repeated cards.

IMPORTANT
---------
Fit Score 5.0 uses deterministic rules plus bounded personal learning signals. Real ML training is available offline only after enough real labels are exported.

ADVANCED MODE
-------------
Run start-assistant.cmd only for the optional local dashboard/server Autopilot/analytics workflows.

GITHUB UPDATE
-------------

Use Publish-Violetta-5.0.0.ps1.
