VIOLETTA APPLY ASSISTANT — WINDOWS QUICK START
=============================================

1. Extract the whole ZIP to a normal folder.

2. Double-click:
   start-assistant.cmd

   The launcher starts the local backend at:
   http://127.0.0.1:8080

   No database installation is required. By default the assistant stores its
   persistent local database here:
   %LOCALAPPDATA%\ViolettaApplyAssistant\jobassistant.db

   Application history, queue state, follow-ups and analytics survive backend
   and computer restarts. The database lives outside the extracted bundle, so
   replacing the bundle with a newer version does not remove local history.

3. FIRST INSTALL ONLY — install the Chrome extension locally:
   - Open chrome://extensions
   - Enable Developer mode
   - Click Load unpacked
   - Select the included "extension" folder
   - Pin "Violetta Apply Assistant"

4. Open the extension's options page / Setup & Readiness.
   Run the system check.

5. Store the two CV PDFs once:
   - English CV
   - Russian CV

6. If you want HH.ru direct API submission, configure HH applicant API credentials locally:
   - Copy user-settings.example.cmd to user-settings.cmd
   - Fill HH__ClientId and HH__ClientSecret
   - Keep user-settings.cmd private
   - Restart start-assistant.cmd
   - In Setup & Readiness click Connect / refresh HH.ru
   - Complete HH OAuth in the browser

   HH is optional. External ATS application preparation works without HH direct API access.

7. Choose a working mode:

   AUTONOMOUS HH MODE
   - Keep the backend window open for the whole working day
   - Open the dashboard and connect HH once
   - Load and select your HH resume
   - Set the minimum fit and daily limit
   - Click "Запустить AI-ассистента"
   - The program collects jobs hourly and checks the HH queue every 10 minutes
   - Click "Остановить" whenever you want to pause it

   MANUAL EXTENSION MODE
   - Open a vacancy in Chrome
   - Open Violetta Apply Assistant
   - Click "Отправить отклик + письмо"
   - The extension prepares the tailored letter, selects/attaches the CV and
     submits only when the final action and required fields are verified
   - If it stops, review the mandatory field shown in the extension and retry

8. The dashboard records who received each application, the exact time,
   whether Autopilot or the extension was used, whether a letter was attached,
   and later HR/interview/rejection/offer updates.

OPTIONAL DATABASE SETTINGS
--------------------------
- The default local SQLite database requires no setup.
- Advanced users can override the SQLite connection using ConnectionStrings__Sqlite.
- PostgreSQL remains supported for a server/shared deployment through ConnectionStrings__Postgres.
  When PostgreSQL is configured it takes precedence over local SQLite.

IMPORTANT
---------
- Never share user-settings.cmd.
- Never paste passwords, SMS codes, CAPTCHA answers or 2FA codes into configuration files.
- Back up %LOCALAPPDATA%\ViolettaApplyAssistant\jobassistant.db if you want an extra copy of local CRM/application history.
- CV Vault PDFs are stored in Chrome local extension storage, not in the backend database.
