# Изменения 6.0.0 RC3

Ключевые изменения релиза: [RELEASE_NOTES_6.0.0.md](docs/RELEASE_NOTES_6.0.0.md).

Документ описывает продуктовый результат и ограничения, а не журнал действий ассистента. Для проверки конкретных требований используйте [матрицу реализации](IMPLEMENTATION_STATUS.md).

## Documentation presentation

README and the core engineering docs were upgraded to a bilingual, architecture-first Senior-level presentation with GitHub-native Mermaid diagrams, local animated workflow artwork, explicit safety/data boundaries and a cleaner canonical documentation map.

## Hotfix · автоматическая отправка «Отклик + письмо»

Кнопка **«✦ Отклик + письмо»** снова выполняет полный пользовательский сценарий за один явный клик. На странице поиска расширение привязывается к точному `vacancyId`, читает полную вакансию в фоне (с HH API fallback), выбирает только подтверждённые и релевантные факты профиля/CV, формирует короткое профессиональное vacancy-specific письмо, открывает штатный HH-flow, заполняет поле, нажимает **«Отправить»** и закрывает окно после подтверждённого результата.

Поддержаны оба HH-сценария: обязательное письмо **до** отправки отклика и добавление письма **после** первичного отклика через «Приложить письмо». На странице конкретной вакансии Apply использует тот же one-shot intent и не требует повторного ручного клика. Поиск обязательных полей теперь ограничен активной application/cover-letter формой, поэтому пустые фильтры на странице поиска не блокируют Send.

Явный клик разрешает только одно финальное действие для текущей связанной вакансии. Фоновый Autopilot не получает дополнительных прав. CAPTCHA, юридические поля, неизвестные обязательные факты, оплата, идентификация, неожиданные uploads и unresolved review остаются fail-closed. Письмо использует правдивое совпадение терминов вакансии с подтверждёнными навыками; это ATS-friendly alignment, а не обещание «обхода ATS».
## Hotfix · повторная отправка письма при «залипшем» окне HH

Некоторые варианты HH оставляли окно **«Сопроводительное письмо»** открытым после первого программного нажатия **«Отправить»**. Из-за этого отклик уже был подготовлен, но письмо фактически уходило только после второго ручного клика.

Теперь расширение заново находит актуальную кнопку после каждого рендера HH, проверяет, что текст письма сохранился, и повторяет отправку до подтверждённого закрытия формы. Цикл ограничен шестью попытками и прекращается сразу после появления подтверждения, закрытия модального окна либо сообщения о просмотренном отклике. Бесконечного клика нет. Логика работает и на странице поиска, и на странице конкретной вакансии. Также поддержано компактное актуальное название действия HH **«Приложить письмо»**.

Регрессионные Chromium-тесты специально моделируют ситуацию, когда первые два Send ничего не делают, а третий закрывает форму. Письмо остаётся неизменным между попытками. Дополнительно устранён ложный PASS: сообщение «Сопроводительное письмо отправлено» у другой карточки больше не считается подтверждением для текущей вакансии.



## Avito Vacancies BETA

Добавлена отдельная интеграция для раздела вакансий Авито. На карточках и странице объявления появляются Analysis, Fit, Calls и подготовка письма. Анализ страницы использует ограниченную параллельность; полное объявление читается в неактивной вкладке и сохраняется под provider-qualified identity, поэтому цифровой ID Авито не смешивается с HH.

Кнопки Analysis/Письмо/Fit/Calls теперь сохраняются при hover-перерисовке карточки Авито. Одно явное нажатие **Письмо** читает точное объявление, создаёт короткий профессиональный текст только из подтверждённых фактов профиля/CV, приводит русские формы к женскому роду, добавляет Telegram и email, нажимает штатную кнопку **Написать**, проверяет exact chat, заполняет composer и отправляет одно сообщение. Отправка подтверждается по очистке поля или появлению текста в чате; повтор ограничен шестью попытками. Avito остаётся BETA / NOT LIVE VALIDATED.

## Hotfix · письма описывают опыт, а не текущую работу

Генератор сопроводительных писем больше не пишет и не подразумевает, что кандидат сейчас трудоустроен. Текущие/старые факты профиля, записанные в настоящем времени, при подготовке письма преобразуются в нейтральное описание имеющегося опыта (например, «есть опыт Technical Support», «работала с SQL», «использовала C#/.NET»). Для технических вакансий подтверждённая GitHub-ссылка по-прежнему добавляется автоматически; для нетехнических ролей она не навязывается. Проверка письма отдельно блокирует фразы вида «сейчас работаю», «работаю в…», `I currently work` и аналогичные утверждения о текущем трудоустройстве.

## Avito chat-send fallback hotfix · 7 октября 2026

Если первичная one-click попытка Avito не смогла открыть точный чат или подтвердить send control, окно сохранённого письма теперь содержит явную основную кнопку **«Отправить в чат»**. Она повторно находит штатную кнопку Avito **«Написать»**, открывает только связанный с вакансией чат, вставляет текущий отредактированный текст, отправляет его и закрывает окно только после подтверждённой отправки. Если правильный чат уже открыт, сообщение отправляется прямо туда без повторного клика по карточке. При ошибке окно остаётся открытым и текст не теряется.
