# 3.8.0 — Candidate Memory & Contextual Writing

- Добавлена миграция ранее установленного профиля на новые CV/HH-источники. Устаревшие непроверенные импортированные факты больше не конкурируют с новым подтверждением.
- AppXite, клиентская разработка и проекты разделены на релевантные проверяемые факты с датами/источниками.
- Письмо получает полную вакансию и отобранные доказательства; snapshot прошлого отклика не подменяет текущий профиль.
- Apply, автопилот, старые dashboard/advanced кнопки используют один путь подготовки письма.
- Для HH list quick apply карточка больше не подменяет полный текст вакансии.
- Чат читает целые сообщения только активной области; последним вопросом не считается последний текст кандидата или превью из соседней беседы.
- Отделены Quick Replies, локальные ответы по фактам и настоящая подключённая модель. Недоступная модель/пустой чат не выдаются за успешный анализ.
- Добавлены конфликты источников, preview без отправки, evidence audit и отдельные пропуски ответа.
- GitHub технический/teaching filter, контроль длины и части неподтверждённых утверждений.
- Безопасный публикационный скрипт заменяет прошлый robocopy + git add -A подход. История не переписывается, binaries не публикуются.

Backend EXE/DLL и оригинальные CV не редактировались. Не заявлены тесты живого HH, внешней модели или Windows runtime.
