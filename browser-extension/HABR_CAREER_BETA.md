# Habr Career beta support

6.0 RC2 enables the content assistant on `career.habr.com`. The adapter can read current vacancy pages, extract vacancy identity/title/description, show the normal on-page assistant, and use generic form/questionnaire Fill when a Habr application form is rendered.

Final native submit remains user-controlled. Logged-in application flows were not exercised by the automated fixture, so Habr is marked **beta**, not equivalent to the HH production path.
