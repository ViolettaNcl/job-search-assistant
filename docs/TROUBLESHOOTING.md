# Устранение проблем

| Симптом | Что проверить |
| --- | --- |
| Нет кнопки Analysis / Apply | Разрешение на сайт, тип страницы, обновление вкладки, отсутствие второй копии расширения |
| Fill не появился | Это действительно форма отклика; controls видимы; контекст связан с выбранной вакансией |
| Поле осталось пустым | Нет подтверждённого факта, неоднозначные варианты или неподдерживаемый custom control — введите ответ вручную |
| Значение исчезло | React/другая логика сайта сбросила DOM; повторите проверку, не считайте поле заполненным по одному событию input |
| Письмо не отправляется | В Assist это ожидаемо: проверьте черновик и используйте штатную кнопку сайта |
| Autopilot отказал | Нет согласия, категория не разрешена, Fit ниже 90, лимит, пауза, неизвестный origin либо риск |
| Нет CV при новой установке | Импортируйте приватный профиль/CV или загрузите PDF в настройках; публичный seed намеренно пуст |
| История пропала после установки | Возможна другая папка/extension ID; не удаляйте старую копию, найдите её и экспортируйте backup |
| Индекс недоступен | Исходная память сохранена отдельно; закройте старые вкладки центра и перестройте индекс |
| .vja не открывается | Верный пароль, поддерживаемая schema, неповреждённый файл, допустимый размер; не редактируйте ciphertext вручную |
| Publisher остановился | Другой origin, не main, незакоммиченные изменения, несоответствие baseline или повреждённый файл; не применяйте force-reset |
| Backend не запускается | В FULL сохранён runtime RC2; проверьте Windows и оригинальные требования. Исходников для его пересборки в архиве нет |

При непонятном поведении остановите массовые действия, сохраните копию и диагностический отчёт. Число пройденных фикстур не гарантирует неизменность живого сайта.
