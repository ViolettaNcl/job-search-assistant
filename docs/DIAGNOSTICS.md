# Диагностика

Центр управления показывает версию, доступность IndexedDB, последнюю миграцию, необходимость перестройки индекса, режим автоматизации, наличие активной модели, выданные host permissions и структурированные локальные коды ошибок.

Разрешение на `hh.ru` не доказывает авторизацию в HH. Фоновый читатель и живой доступ отмечены **NOT_LIVE_VALIDATED**, пока соответствующий smoke-test не выполнен. Значение «IndexedDB недоступен» не означает, что прежняя Chrome-память удалена.

## Передача отчёта

Откройте **Диагностика → Скопировать** либо скачайте диагностический файл. Добавьте отдельно: действие, адрес без личных токенов, ожидаемое и фактическое поведение. Не присылайте cookies, API-ключи, полный CV, приватный FULL и полный backup в публичный issue.

Логи содержат INFO/WARN/ERROR, timestamp, version, module, error code и vacancyId при наличии. Произвольные тексты ошибок/сообщений не должны автоматически копироваться в диагностический журнал. Это ограниченная структурированная телеметрия, не полный сетевой трассировщик.

## Типовые действия

При ошибке индекса закройте другие вкладки центра и выполните **Перестроить индекс**. При отказе отправки проверьте режим, паузу, категорию, Fit и обязательные поля; не отключайте защиту для обхода CAPTCHA или юридического вопроса. При ошибке restore остановитесь и используйте сохранённый checkpoint/экспорт.
