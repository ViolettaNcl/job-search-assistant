# 5.0 release history

## 5.0.0 Foundation

A consolidated architecture milestone built on the verified 4.0 workflow.

Highlights:

- Personal Learning Event Store with implicit Apply/Save/Skip and explicit Fit feedback.
- Explainable bounded personalization layered on top of the deterministic Fit score.
- Separate visible Fit and Calls indicators.
- Learning Center with local export/import/reset controls.
- Outcome funnel and application timeline foundations.
- Recruiter intent classification and vacancy-aware interview preparation.
- Cross-ID duplicate/repost advisory.
- Formal JobSiteAdapter contract for future providers while HH remains the primary verified live integration.
- Real offline preference-model training/evaluation/registry/promotion tooling.
- Synthetic test-only models cannot be promoted and are not described as trained personal models.

No active trained personal ML model is bundled by default. Real labels must first accumulate through actual use.
