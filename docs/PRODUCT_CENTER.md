# Центр управления 6.0 RC1

Откройте popup → «Центр управления». Данные читаются локально при открытии и по «Обновить». Вкладка не запускает отклики или обход сайта.

«Обзор» показывает сохранённые данные этого расширения. «Последние 7 дней» — скользящее окно, не календарная неделя; повторные события Apply одной вакансии считаются один раз.

«Отклики и журнал»: поиск по должности/компании, по 25 записей, журнал выбранной заявки. Оригинальные объявления открываются только вашим нажатием.

«Качество данных»: 100 labels — минимальная проверка, не обещание качественной модели. Нужны оба класса, разные вакансии, признаки и временные метки. Save/Skip — косвенные, потенциально шумные сигналы.

«Shadow»: импортируйте candidate через Learning Center, выберите его здесь. Новые или принудительно повторно анализируемые вакансии получают теневое предсказание. Оно не меняет Fit. Таблица сравнения становится содержательной только после дальнейших пользовательских решений.

«Откат»: возвращает сохранённую предыдущую модель того же типа, проверяя её artifact/hash. Когда предыдущей модели нет, используйте Disable в Learning Center.

«Диагностика»: выгружает счётчики/версию/возможности среды, но не CV, контакты, вопросы, названия вакансий, токены. Это не тест авторизации на HH.
