# Центр управления

Обзор, поиск/история, отклики/журнал, очередь, сообщения, интервью, аналитика, данные, модели, backup, диагностика, настройки и первый запуск находятся в едином интерфейсе.

Обзор показывает только сохранённые локальные события. Поиск/история не выполняет скрытый массовый поиск на сайтах. Индексируемые списки разбиты по 25 записей. Фоновая перестройка не удаляет исходную память.

Аналитика предлагает группировку по роли, CV и письму. Выводы для маленьких выборок ограничены. Follow-up — текст для просмотра. В самом центре нет кнопки немедленной отправки работодателю.

Первый запуск — проверяемый импорт и список из десяти пунктов настройки, а не завершённый пошаговый wizard всех полей. Подробные изменения профиля открываются отдельно.

Интерфейс имеет видимый focus, подписи полей, live-status, адаптивную раскладку и reduced-motion. Скриншот README снят на фиктивных данных; он не показывает реальные результаты кандидата.
