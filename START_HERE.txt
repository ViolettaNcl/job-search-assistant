ANALYSIS НА КАРТОЧКЕ HH
-----------------------
Нажмите Analysis рядом с нужной вакансией: ✓ Без звонков = можно рассматривать для chat-only; ✕ Есть звонки = в полном описании найдены телефонные/голосовые обязанности; ? Неясно = полное описание не подтверждено. Analysis сам отклик не отправляет.

БЫСТРЫЙ ЗАПУСК БЕЗ ТЕРМИНАЛА
1. Распакуйте ZIP.
2. Chrome -> chrome://extensions
3. Включите Режим разработчика.
4. Нажмите "Загрузить распакованное".
5. Выберите папку extension.

Готово. Базовые функции работают как Chrome extension:
- ✦ Apply на поддерживаемой вакансии
- ✎ AI в текущем recruiter chat
- HH quick apply + vacancy-specific cover letter
- Candidate Truth Memory
- RU/EN CV
- локальные ответы по подтвержденным фактам

Если HH был открыт до установки/обновления расширения, 3.9.7 пытается
подключиться к уже открытой вкладке. Если Chrome не разрешил переинжект,
один раз обновите вкладку.

✦ APPLY
На прямой HH-вакансии кнопка должна быть в правом нижнем углу.
Она не зависит от готовности локального backend.
При SPA-переходах 3.9.7 повторно проверяет тип страницы и восстанавливает UI.

✎ AI
В активной HH-переписке ручка должна появляться по умолчанию.
Она работает по текущему открытому чату, а не по "последней вакансии".
Send остается ручным.

ПИСЬМА И MEMORY
Используются актуальные подтвержденные факты из CV/HH/current Technical Support/freelance memory.
Для каждой вакансии отбираются только релевантные факты.
В сопроводительном письме не называются прежние работодатели или учебное заведение: используются роль, релевантные обязанности, проекты и профильное образование в области информационных систем и программирования.
GitHub добавляется только для технических ролей.

ВНЕШНЯЯ AI-МОДЕЛЬ
Не обязательна для базовых функций.
Настройки -> AI и ответы -> Модель.
Без модели работает локальный evidence-based режим.

HH.RU — ПОСТОЯННЫЙ ✦ APPLY / ✎ AI
----------------------------------
На вакансиях и в переписке кнопки должны появляться автоматически.
Если Chrome раньше был вручную переведён в режим «доступ только при нажатии», браузер не разрешает расширению отменить это без вашего действия. Разрешите доступ к HH.ru один раз. В 3.9.7 это разрешение запрашивается сразу для hh.ru и всех региональных *.hh.ru. После этого открывать popup для каждой вакансии не требуется.

Нажатие ✦ Apply запускает полный поддерживаемый flow: анализ вакансии → CV → индивидуальное сопроводительное письмо → штатный «Откликнуться» → «Приложить сопроводительное письмо» → заполнение поля → «Отправить». Если сайт требует неоднозначного обязательного решения, flow останавливается на проверку.

FAST CARD APPLY FROM THE VACANCY LIST
------------------------------------
On HH.ru / HeadHunter search result pages the extension adds:

✦ Отклик + письмо

next to supported vacancy cards. Press it to highlight that exact card and send the response with a vacancy-specific cover letter without manually opening the detail page.

Supported HeadHunter variants:
- cover letter is mandatory before the initial response;
- response is sent first and HH then shows «Приложить письмо».

Unsupported/ambiguous questionnaires stop for review.
