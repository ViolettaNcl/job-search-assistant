VIOLETTA APPLY ASSISTANT 3.7.0
==============================

QUICK START
-----------
Packaged Windows release:

1. Run start-assistant.cmd
2. Reload Violetta Apply Assistant in chrome://extensions
3. Refresh already-open HH.ru / recruiter-chat tabs
4. Use:
   🚀 Autopilot
   ✦ Apply
   ✎ AI

LOCAL BACKEND
-------------
http://127.0.0.1:8080

If readiness fails:
BACKEND_DIAGNOSTICS.cmd

Local SQLite data is stored outside the release folder under:
%LOCALAPPDATA%\ViolettaApplyAssistant

SOURCE REPOSITORY
-----------------
browser-extension\             Chrome extension source
src\JobSearchAssistant\        .NET backend source
tests\                         tests
scripts\                       verification / packaging helpers
tools\                         maintenance helpers
docs\                          docs + assets + history

Generated backend binaries are release artifacts and are not stored in Git.

✦ APPLY
-------
Open a supported vacancy and press ✦ Apply.

Expected:
analyze vacancy
→ choose RU/EN CV
→ generate short cover letter
→ run supported application flow
→ confirmed / review required / failed

HH QUICK APPLY
--------------
On HH.ru search results, press the native «Откликнуться».

For a supported unambiguous flow the assistant can prepare and attach the cover letter for that exact vacancy card.

✎ AI
----
Open the recruiter conversation you want to answer.

Press:
✎ AI → «🧠 Проанализировать весь диалог и ответить»

The assistant reads accessible context and prepares a draft for the latest recruiter message.

You review and send the message yourself.

🚀 AUTOPILOT
------------
Open the compact extension popup.

Press:
🚀 Запустить автопилот

Default focus:
- remote IT
- C# / .NET
- ASP.NET Core
- Backend
- Full-Stack .NET
- QA / QA Automation
- Technical Support

Clearly unsuitable senior-level roles are skipped.
Session/day limits are enforced.
Ambiguous high-risk required fields stop the current application.

COVER LETTERS
-------------
Technical letters are short and vacancy-specific.

Relevant IT letters may include:
https://github.com/ViolettaNcl

They prioritize technical projects/skills instead of repeating unrelated experience.

IMPORTANT
---------
- Do not invent candidate facts.
- Salary / visa / legal / privacy ambiguity requires review.
- Recruiter Send remains manual.
- CAPTCHA/MFA is not bypassed.
- External sites can change DOM; use a small live smoke test after major UI changes.
