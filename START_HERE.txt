VIOLETTA APPLY ASSISTANT 3.7.0
==============================

ОБНОВЛЕНИЕ СУЩЕСТВУЮЩЕЙ УСТАНОВКИ
---------------------------------
1. Распакуйте весь ZIP в отдельную папку рядом со старой.
2. Закройте старое окно/сервер JobSearchAssistant. При необходимости запустите STOP_ASSISTANT.cmd.
3. НЕ удаляйте существующее расширение из Chrome.
4. Запустите UPDATE_EXISTING.cmd из новой папки.
5. Укажите путь к старой папке проекта (там должны быть extension и backend).
6. В chrome://extensions нажмите Reload / «Обновить» у существующего Violetta Apply Assistant.
7. Обновите открытые вкладки HH.ru и recruiter chat.
8. Запустите start-assistant.cmd из обновлённой рабочей папки.

BACKEND
-------
Используется http://127.0.0.1:8080. Launcher не должен сам открывать dashboard.
Если readiness не становится green, запустите BACKEND_DIAGNOSTICS.cmd и проверьте:
%LOCALAPPDATA%\ViolettaApplyAssistant\backend-diagnostic.txt
Логи: %LOCALAPPDATA%\ViolettaApplyAssistant\logs
Не удаляйте jobassistant.db для «исправления» startup.

✦ APPLY НА ОТКРЫТОЙ ВАКАНСИИ
----------------------------
Нажмите плавающую ✦ Apply. Расширение остаётся в текущем employer flow: анализирует vacancy, выбирает RU/EN CV, создаёт короткое письмо, заполняет форму и выполняет финальный отклик, если preflight однозначен.

БЫСТРЫЙ ОТКЛИК ИЗ СПИСКА HH
---------------------------
На странице поиска HH можно просто нажать штатную синюю кнопку «Откликнуться» на нужной карточке.
Если HH подтверждает быстрый отклик и показывает «Приложить письмо», assistant автоматически создаёт письмо именно по этой карточке, открывает форму письма, вставляет его и отправляет — без открытия vacancy detail.

Функция запускается только после реального пользовательского клика по native кнопке и может быть отключена в Settings → Автоотклик.
Если HH открывает сложную форму или UI неоднозначен, assistant прекращает этот shortcut, а не кликает случайно.

✎ AI — ТЕКУЩИЙ ЧАТ
-------------------
Ручка должна отображаться в detected recruiter chat, включая старые/unlinked chats.
Нажмите ✎ AI → «🧠 Проанализировать весь диалог и ответить».
Assistant читает доступную историю именно открытого сейчас чата, определяет latest recruiter message и незакрытые вопросы и готовит один draft.

Также доступны: ответить на последнее сообщение, улучшить мой текст, вопрос работодателю, быстрые ответы.
AI draft только вставляется. Recruiter Send нажимаете вы.

🚀 АВТОПИЛОТ
------------
Откройте обычное компактное окно расширения и нажмите «🚀 Запустить автопилот».
Агент начинает только после вашего нажатия. Кнопка меняется на «⏹ Остановить автопилот».

По умолчанию он:
- ищет remote IT-вакансии через HH в Chrome;
- использует match score и Candidate Truth Profile;
- ориентируется на C#/.NET/Backend/Full-Stack/QA/Technical Support;
- пропускает явные Middle/Senior/Lead/Manager роли;
- открывает подходящие вакансии в фоновых вкладках;
- отправляет короткое vacancy-specific письмо и отклик;
- останавливает конкретную вакансию на salary/visa/legal/privacy и других неоднозначных обязательных полях.

Под кнопкой видны threshold, счётчик сессии и дневной лимит. Расширенные search queries/limits доступны через «Дополнительно → Настройки автопилота».
