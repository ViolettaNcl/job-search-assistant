WINDOWS RELEASE / EXISTING INSTALLATION
---------------------------------------
If you are using a packaged Windows release:

1. Stop the old backend if it is running.
2. Keep the existing unpacked Chrome extension if you want to preserve its local storage.
3. Use UPDATE_EXISTING.cmd from the new release bundle.
4. Reload the extension in chrome://extensions.
5. Refresh already-open HH.ru / recruiter-chat tabs.
6. Run start-assistant.cmd.

✦ APPLY
-------
On an opened supported vacancy press ✦ Apply.

Expected flow:
vacancy analysis
→ RU/EN CV selection
→ short vacancy-specific cover letter
→ supported application handling
→ confirmed / review required / failed

Normal Apply should stay on the employer site.

HH QUICK APPLY
--------------
On an HH.ru search-results page you can press the native blue «Откликнуться».

For supported unambiguous flows the assistant can prepare and attach a cover letter for that exact vacancy without requiring you to open the detail page manually.

✎ AI — CURRENT RECRUITER CHAT
------------------------------
Open the recruiter conversation you want to answer.

Press:
✎ AI → «🧠 Проанализировать весь диалог и ответить»

The assistant reads the accessible current conversation and prepares a draft for the latest recruiter message.

You review the draft and send it yourself.

🚀 AUTOPILOT
------------
Open the compact extension popup and press:

🚀 Запустить автопилот

The agent starts only after your click.

Default focus:
- remote IT roles
- C# / .NET
- ASP.NET Core
- Backend
- Full-Stack .NET
- QA / QA Automation
- Technical Support

Clearly unsuitable Middle/Senior/Lead/Manager roles are skipped.

The agent respects match/session/day limits and stops on ambiguous high-risk required fields.

COVER LETTERS
-------------
Technical cover letters are short and vacancy-specific.

For relevant IT roles they may include:
https://github.com/ViolettaNcl

Developer/QA letters prioritize relevant technical projects/skills instead of repeating unrelated hospitality experience.

IMPORTANT
---------
- Do not invent candidate experience or years.
- Ambiguous salary/visa/legal/privacy/work-authorization questions require review.
- Recruiter Send is manual.
- CAPTCHA/MFA is not bypassed.
- Employer sites change their UI; run a live smoke test after major site changes.
