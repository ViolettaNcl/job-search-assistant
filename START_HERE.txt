VIOLETTA APPLY ASSISTANT 3.9.13 — START HERE
=============================================

NORMAL USE (NO TERMINAL REQUIRED)
---------------------------------
1. Extract the ZIP.
2. Open Chrome -> chrome://extensions
3. Enable Developer mode.
4. Click "Load unpacked".
5. Select the "extension" folder from the FULL bundle.
6. Grant HH.ru / HeadHunter access if Chrome asks.
7. Reload already-open HH tabs once.

SEARCH PAGE
-----------
Analysis             -> reads the exact full vacancy and checks call duties.
✦ Отклик + письмо    -> prepares an exact-vacancy application and cover letter.

QUESTIONNAIRE PAGE
------------------
The assistant reads employer questions and fills safe answers from candidate evidence.

✓ auto-filled        = confirmed evidence
✎ draft/review       = neutral human fallback, check before sending
? / review           = data cannot be safely inferred

The assistant does not invent legal/identity facts or numeric salary values.

MEMORY
------
Analysis, application and questionnaire state are stored by vacancyId and restored after Back/reload/repeated cards.

ADVANCED MODE
-------------
Run start-assistant.cmd only if you need the local dashboard, queue, Autopilot or server analytics.
Default backend: http://127.0.0.1:8080
