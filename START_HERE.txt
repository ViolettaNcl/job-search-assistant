VIOLETTA APPLY ASSISTANT 3.8.0
=============================

ОБНОВИТЬ УСТАНОВЛЕННУЮ ВЕРСИЮ
1. Распакуйте весь ZIP рядом со старой папкой, не внутрь неё.
2. Остановите старый backend: STOP_ASSISTANT.cmd.
3. Запустите UPDATE_EXISTING.cmd из новой папки, выберите старую установленную папку.
4. Не удаляйте расширение Chrome: нажмите Reload в chrome://extensions.
5. Обновите открытые вкладки HH и чатов.
6. Запустите start-assistant.cmd из обновлённой старой папки.

ПЕРВЫЙ ЗАПУСК
Распакуйте весь ZIP. Chrome → chrome://extensions → Режим разработчика →
Загрузить распакованное → папка extension внутри пакета.
Запустите start-assistant.cmd. Одного запуска сервера недостаточно без расширения.

ПРОФИЛЬ
Настройки → Профиль → Память CV и HH.
Версия источников: 2026-09-28.1; добавлены ваши AppXite и фриланс-сведения.
PDF сохранены без переписывания. В них AppXite не добавлялся: новые данные
находятся в памяти профиля по вашему тексту HH. Неизвестные факты не угадываются.
Ручные CV и контакты при обновлении не должны перезаписываться.

ПИСЬМА
В настройках есть предпросмотр по полному тексту вакансии, без отклика.
Apply / автопилот используют актуальные факты и полную вакансию.
Из списка HH полная вакансия может открываться в неактивной вкладке для чтения,
но текущая вкладка не переключается на внутреннюю страницу расширения.
При ошибке чтения письмо не отправляется по короткой карточке.

ЧАТ
Откройте нужную переписку → ✎ AI → Проанализировать весь диалог и ответить.
Проверьте блок «Что прочитано и на чём основан ответ».
Неизвестный автор / пустой чат / неполная история показываются явно.
Ответ можно вставить; Send всегда нажимаете вы.

AI-МОДЕЛЬ
По умолчанию работают локальные ответы по фактам и короткие письма.
Для свободных ответов, сложных вопросов и «Улучшить текст»:
Настройки → AI и ответы → Модель для свободных ответов.
Укажите совместимый endpoint /chat/completions, модель, ключ и согласие.
Пример endpoint: https://openrouter.ai/api/v1/chat/completions
Идентификатор модели берётся из вашего аккаунта провайдера; он не выдуман в пакете.
Ключ хранится на текущий сеанс Chrome; после полного перезапуска введите его снова.
Внешняя модель может быть платной. Ключ не отправляйте в чат или GitHub.

GITHUB
Запустите SYNC_GITHUB.cmd либо Publish-Violetta-3.8.0.ps1 -Push.
Отдельно скачанный PS1 предложит выбрать этот полный ZIP.
По умолчанию репозиторий: %USERPROFILE%\Downloads\job-search-assistant
Копируются только исходники/тесты/документация из проверенного списка.
Рабочая папка должна быть чистой. При divergence или ошибке push скрипт остановится.
Никаких reset --hard, force-push, git clean и удаления базы.
CV и факты в публичном GitHub будут видны всем; учитывайте видимость репозитория.

BACKEND
http://127.0.0.1:8080
При ошибке: BACKEND_DIAGNOSTICS.cmd. Базу не удалять.
